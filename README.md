# Description
FontX - Persian Fonts
A lightweight and practical plugin for Persian fonts with !important applied styling.

`فونت با !important اعمال میشود تا از حداکثر اولویت و تأثیر گذاری در اجرا اطمینان حاصل گردد`

To add a custom font, upload the font files to the /fonts folder

`میتوانید فونت های خود را در پوشه fonts بارگذاری و سپس افزونه را نصب کنید`

Default fonts: 7 options available (IranSansWeb, KalamehWebBold, Shabnam, Nahid, Vazir, Parasto, Tanha)

`افزونه دارای 7 فونت پیشفرض می‌باشد ( ایران سنس، کلمه، شبنم، ناهید، پرستو، وزیر، تنها ) `
