# FontX
Developer : Ali Rezaei, Ovan Develop

# Description
FontX - Persian Fonts
A lightweight and practical plugin for Persian fonts with !important applied styling.

To add a custom font, upload the font files to the /fonts folder

Default fonts: 7 options available (IranSansWeb, KalamehWebBold, Shabnam, Nahid, Vazir, Parasto, Tanha)
